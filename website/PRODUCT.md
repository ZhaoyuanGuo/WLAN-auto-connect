# PRODUCT.md — 官网的产品事实

> 这份文件只写**产品事实**：给谁用、在什么场景用、有什么硬约束、什么算做好了。
> 视觉方向与设计系统一律不写在这里，见 `DESIGN.md`。
> 目的：把这些年只存在于脑子里、每次改官网都要重新交代一遍的背景落到纸上。
> 维护规则：事实变了就改这里；改不动的地方就是产品的问题，不是文档的问题。

## 一句话

辽宁警察学院（LNPC）校园网 **LNPC-STU** 的静默自动登录工具的官方网站：说明它做什么、
把正确的安装包/快捷指令交到正确的人手里、并让零基础的人在 3 分钟内配通。

## 给谁用（以及不是给谁用）

| 事实 | 对官网的含义 |
|---|---|
| 用户是本校在校学生与教职工，绝大多数在**手机上**第一次接触本站 | 移动端是主场景，不是"顺便适配" |
| 典型时刻：刚拿到新手机 / 开学第一天 / 认证页一直弹 | 首屏必须在 3 秒内回答"我该点哪个下载" |
| 用户不懂 Dr.COM、eportal、ABI、DPAPI 这些词 | 术语只在需要精确时用，且必须就地解释（如"64 位（arm64-v8a）"） |
| 用户没有技术支援，只有这篇图文教程 | 教程的可信度 = 产品的可信度；真机截图是核心资产 |
| **不是** SaaS 落地页，没有竞品、没有定价、没有注册转化漏斗 | 禁止 social proof 数字滚动、禁止"限时/免费试用"话术、禁止堆 feature 卖点 |

## 隐私红线（产品承诺，不是营销话术）

1. **默认全本地**：Windows 用 DPAPI 加密文件、Android 用应用沙箱、iOS 快捷指令写本机 `campus.txt`（不同步 iCloud）。
2. **云端同步默认关闭**，只在用户主动注册后加密上传自建服务器，可随时删。
3. **无统计、无埋点、无行为上报**；除认证服务器与可选同步服务器外不连任何外部服务器。
4. **share.html / share-code.html 涉及账号密码**，因此：`noindex`、不接任何第三方 SDK（在线客服只出现在首页）、编码全在浏览器本地完成。

第 3、4 条不是建议，是本站最容易被"顺手加个统计"破坏的东西，已写成可执行断言。

## 硬约束（改官网前必须先读）

- **纯静态**：`website/` 下无构建步骤、无框架、无 npm 依赖。任何"要先 build 一下"的方案都不属于本站。
- **同层部署**：`index.html` 与 `share.html` 必须在站点根同一层级，引用一律用相对同层路径。
- **站点根有两个仓库外的文件/目录**：`/ga_beian.png`（公安备案图标，页脚引用它）与 `/dl/`（安装包目录）。**任何同步都不能删除它们**，所以部署是逐文件 scp，不是整目录 rsync。
- **部署方式**：scp 上传；覆盖前先备份线上文件（`index.html.bak.<标记>-<时间戳>`）；上传后属主改 `www:www`。
- **合规**：页脚必须保留 `辽ICP备2026022980号` 与 `辽公网安备21020302000662号`（带可核对的查询链接）、以及"请遵守所在学校/单位的网络管理规定"的免责句。
- **辅助工具要固定版本**：联网检测守护可选 Shizuku 方案，**固定推荐 v13.5.4**（v13.6.0 在部分联发科机型无法启动服务），并提供 SHA-256 校验与 `dl.suspect.top` 高速兜底直链。这条是实测结论，改版时最容易被"帮你升级到最新版"弄丢。

## 核心决策（为什么是现在这个样子）

- **D1 · UA 智能主按钮**：Hero 只有一个主下载按钮，按 `navigator.userAgent` 改写为对应平台的直链并隐藏重复入口；识别不了（Mac / Linux / iPad 桌面模式）就回落到滚动到三平台下载区。理由：手机用户占多数，而"在手机上下载了 .exe"是最常见的失败。
- **D2 · Android 不自动判架构**：点了"获取 Android 版"必须人肉选包，弹窗里给"不确定就选 64 位"。理由：UA 无法可靠区分 arm64-v8a 与 armeabi-v7a，猜错的代价是安装失败，比多点一次贵。
- **D3 · 首页不放下载量等统计数字**：下载统计走服务器日志，页面不显示。理由：显示不出可核对来源的数字就是编，而这个站的资产是可信度。
- **D4 · 教程以真机截图为主**：`help-assets/` 按 windows / android / ios 分目录，共 27 张实拍。理由：真实截图是证据，假界面图是装饰，而本站要的是证据。
- **D5 · 分享码方案降为备选**：`share.html`（iCloud 母版 + 本机存储）是主推，`share-code.html`（剪贴板、每次要重新复制）放在下方"不方便把密码存本机？"的位置。理由：主路径必须是免重复操作的那条。

## 做好了的标准

1. 一个新生用自己手机打开首页，不查资料就知道下哪个包、怎么装。
2. 照着 `help.html` 走完，不求助就能配通开机自动认证。
3. 页面上每一句隐私与安全承诺，都能在代码/产物里核对。
4. 合规信息齐全（备案号、公安备案、免责句、校验值）。
5. 一年后回看，页面传达的是"有人做过决定"，而不是"某套模板长这样"。
