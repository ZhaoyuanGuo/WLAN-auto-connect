核心功能

静默自动认证

连接校园网 WiFi 后自动抓取门户会话参数，调用 eportal 接口完成认证，无需打开认证网页

一键连接

自动连接目标 WiFi 并等待关联完成后发起认证，一条命令完成从联网到认证的全流程

开机自启认证

Windows 通过任务计划、Android 通过 WorkManager + 开机广播，登录系统后静默完成认证

桌面小组件 / 磁贴

桌面小组件与控制中心磁贴实时显示连接状态，一键触发认证，无需打开应用

密码本地加密

Windows 使用 DPAPI 加密，Android 保存于应用沙箱，仅本机可解密，不共享不上传

联网检测守护

可选关闭系统强制门户探测，避免认证前被系统抢占式弹出浏览器，认证全程静默

隐私与安全

数据仅本地保存

账号、密码及各 WiFi 配置默认仅保存在本机（Windows 为 DPAPI 加密文件，Android 为应用沙箱），不共享、不收集。

可选云端同步

默认关闭。仅当您主动注册登录后，才将 WiFi 配置加密上传到自建服务器做备份，用于多设备恢复，可随时删除。

无统计无埋点

软件不含统计、埋点或行为上报，除校园网认证服务器与可选同步服务器外，不连接任何其他外部服务器。
